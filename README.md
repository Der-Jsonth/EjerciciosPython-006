# **EjerciciosPython-006**

## Ejercicio Tipo Prueba

##### 👤 Desarrollado por: Matías González

##### 🧙‍♂️ Aldric, el Comerciante Arcano



Sistema de gestión de inventario para un NPC mercader de un videojuego MMORPG de fantasía.



Este proyecto consiste en desarrollar un programa en Python que permite administrar una tienda de objetos mágicos mediante un menú interactivo. El sistema permite consultar inventario, buscar objetos, modificar precios y visualizar el catálogo completo.



El ejercicio está enfocado en practicar fundamentos de programación utilizando:



* Diccionarios
* Listas
* Funciones
* Ciclos repetitivos
* Condicionales
* Manejo de excepciones
* Manipulación de datos

📖 Contexto



En el mundo de Eldoria Online, Aldric es un comerciante encargado de vender objetos mágicos a los aventureros.



Cada objeto posee información como:

* Nombre
* Categoría
* Rareza
* Tipo de magia

Además, el sistema controla:

* Precio del objeto
* Cantidad disponible en inventario



🎯 Objetivo del proyecto



Aplicar conceptos fundamentales de programación mediante la creación de un sistema de gestión basado en estructuras de datos, simulando el funcionamiento interno de un NPC comerciante dentro de un videojuego MMORPG.
